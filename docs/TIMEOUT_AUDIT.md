# Проверка таймаутов Pi Studio

Проверено 17 ноября 2026 года: собственный runtime в `src/`, адаптеры
`bundled/pi-bridge/`, helper обновлений и таймауты неизменённого закреплённого
провайдера Claude Code. Таймеры анимации, опроса, сохранения и срока хранения
проверены отдельно от ограничений длительности операций. Тестовые и сборочные
ограничения не считаются ограничениями пользовательского runtime.

## Исправления

| Операция | Было | Стало и причина |
| --- | --- | --- |
| Загрузка видимого Chrome, headless Chrome, agent-browser | 3 минуты на весь запрос и тело | 60 секунд до заголовков, затем 60 секунд без новых данных. Пока передача идёт, общего лимита нет. |
| Загрузка Node.js для Pi | 2 минуты на весь запрос и тело | Та же политика заголовков/простоя. Проверка закреплённого SHA-256, размер, отмена и owned staging сохранены. |
| Распаковка Chrome | 1 минута | 5 минут: архив до 300 MiB, в Windows используется PowerShell Expand-Archive. |
| Просмотр/извлечение agent-browser tar | Без ограничения времени | 5 минут, плюс прежние ограничения размера и проверка путей/бинарника. |
| Распаковка Node.js | 3 минуты | 5 минут. При таймауте дочерний процесс должен завершиться до очистки staging. Ошибка запуска снимает таймер. |
| npm ci для Pi, native install-package | 3 минуты | 15 минут: установка множества пакетов по сети. Отмена Pi и ограничение native subprocess сохранены. |
| Images API generation/edit | 3 минуты | 10 минут на операцию, 60 секунд простоя при чтении тела. Платный запрос автоматически не повторяется, неизвестный результат остаётся uncertain. |
| Внутренний MCP pi_studio | 4 минуты | 20 минут: больше 15-минутной установки и 10-минутной генерации, с запасом на подготовку/сохранение. Только generate_image/install_package и прежний team wait отправляют SSE-заголовки сразу и комментарии каждые 15 секунд, если клиент принимает SSE. JSON-клиенты поддерживаются. |
| Глубокая проверка подписи Mac | 30 секунд | 2 минуты на каждую проверку большого bundle на холодном/медленном диске. |
| Метаданные подписи, plutil, lipo | Часть без ограничения | 10 секунд на короткую локальную команду. |

Ошибки ожидания сервера и простоя загрузки локализованы на RU/EN. Ошибка
оставляет кнопку повторной установки доступной; самопроизвольных повторов нет.
Новая политика загрузок не меняет источники, запрет редиректов, закреплённые
версии, контроль суммы, лимиты размера или правила публикации компонента.

## Проверенные ограничения, сохранённые без изменения

| Область | Политика и обоснование |
| --- | --- |
| GitHub updater | 60 секунд заголовки и 60 секунд простоя каждого чтения; нет общего времени здоровой загрузки. Сохраняются resume/Range, подпись, хеш, отмена и owned cleanup. |
| Транзакция обновления | Выход старого приложения 120 секунд, здоровье нового 90 секунд, остановка неуспешного 30 секунд. Подготовка/helper acknowledgement 15 секунд. Превышение ведёт к явной ошибке/восстановлению, не к удалению неопределённой копии. |
| Пользовательский вход OAuth | 5 минут, явная отмена. Это ожидание действия человека с возможностью начать вход заново, не длительность рабочего диалога. |
| Каталоги/авторизация моделей | 20 секунд внешняя операция; локальный endpoint 12 секунд, Claude status до трёх команд по 5 секунд. Есть запас внешнего лимита; значения/секреты не выводятся. |
| Native resources | MCP handshake 30 секунд внутри 45 секунд внешней проверки; быстрые configure/list/check-package до 45 секунд. Это проверка готовности, установка вынесена в отдельную 15-минутную операцию. |
| Открытие Pi | Подтверждение 45 секунд, MCP readiness 20 секунд, отдельные ограниченные probes. Рабочий диалог после открытия этим таймером не ограничен. |
| Живой Pi | Heartbeat каждые 3 секунды, локальный запрос 10 секунд, liveness 20 секунд. Открывающийся диалог исключён из heartbeat expiration; доказанно умерший процесс обрабатывается сразу. |
| Windows Terminal | Видимый detached запуск без таймаута времени жизни окна. Скрытый процессный probe 5 секунд; проверка session owner 15 секунд на холодной Windows / 2 секунды POSIX. Неудача probe не равна доказанному закрытию. |
| Mac Terminal | Короткие probes 2 секунды, AppleEvents 10 секунд, проверка закрытия 3 секунды. Неопределённый AppleEvent не повторяется автоматически и не даёт права закрыть чужой диалог. |
| Browser Use | Каждая ограниченная CLI-команда 30 секунд, DevTools 10 секунд, внутренний MCP 120 секунд. Время простоя браузерного движка 2 минуты — освобождение ресурса с отдельным профилем, не лимит установки. |
| Computer и остальные внутренние группы | Внешние запросы 120 секунд, локальные снимки/действия не используют установочный сетевой лимит. Overlay освобождается после 1,8 секунды бездействия. |
| Team say_to / say_to_agent | Ожидание завершения без общего таймаута, с отменой/отключением и SSE heartbeat. Не повторяется с новым request_id после неизвестного результата. |
| Проверки версий/платформы/путей | Обычно 10 секунд, provider probe 15 секунд, reference conversion 20 секунд, accounting CLI 15 секунд, ACL 10 секунд. Ограничены короткие команды, не интерактивные окна. |
| Чтение файлов | 10 секунд read deadline, ограничения размера, проверка обычных файлов/символических ссылок. Сохранение пользовательских данных этим таймером не прерывается. |
| Закреплённый Claude Code | Поток ожидает очередное событие до 180 секунд, служебные команды до 20 секунд. Это таймаут простоя событий, не общий срок активной генерации. Upstream-файлы/хеши не менялись. |
| Внешние MCP | Собственные настройки пользователя/официального SDK сохранены. Глобальная замена таймаутов чужих серверов не выполнялась. |
| UI и фоновые таймеры | Debounce сохранения 250 ms, «Сохранено» 3 секунды, Notice 4,5/10 секунд, readiness polling, двухчасовое старение завершённых onboarding tasks, трёхчасовой star reminder. Не прерывают установку, рабочий диалог или сохранение. |

## Проверки и границы доказательств

- `tests/transfer-deadlines.test.ts`: снятие таймера заголовков, поздний ответ,
  медленный поток, пустые chunks, зависание, отмена, RU/EN, HTTP downloader,
  завершение дочернего процесса до очистки, SSE success/error без повтора вызова.
- `scripts/smoke-slow-browser.ts`: настоящий HTTP-поток дольше прежних 180 секунд,
  проверка SHA-256; реальные 60-секундные header/idle failures через installer
  с удалением его staging. Браузерные бинарники не запускаются.
- `scripts/smoke-onboarding.mjs`: реальный собранный renderer в изолированном
  headless shell, обе новые ошибки в BrowserResourceStatus на русском и
  английском, disabled во время установки и доступный повтор после ошибки.
- Полный набор unit/FS/protocol tests, typecheck, lint и сборка. Выпуск проверяет
  подписи, ZIP, inventory и совпадение compiled payload для Mac/Windows.

Проверки не устанавливают и не перезапускают пользовательскую Studio, не
запрашивают системные разрешения и не заменяют нативную Windows-приёмку или
подтверждение следующего обновления самим пользователем.
